# معما چیستان — نسخه پایه قابل ساخت

این پروژه یک نسخه پایه اندرویدی با Java است: منوی فارسی، فهرست مراحل، معما، راهنما و سکه‌ها.
برای اینکه ساخت اولیه روی فضای ابری ساده‌تر باشد، تبلیغات، پرداخت مایکت و سرویس اعلان در این نسخه فعال نیستند؛ شناسه‌های تبلیغاتی نمونه و کدهای پرداخت ناقص عمداً حذف شده‌اند.

## ساخت APK فقط با گوشی
1. فایل ZIP را از حالت فشرده خارج کن.
2. پوشه پروژه را در یک مخزن خصوصی GitHub بارگذاری کن (از مرورگر گوشی هم ممکن است).
3. تب **Actions** را باز کن و workflow با نام **Build Android APK** را اجرا کن.
4. پس از پایان موفق، در همان اجرای workflow بخش **Artifacts** فایل `MoamaChistan-debug-apk` را دانلود کن.
5. ZIP آرتیفکت را باز کن و `app-debug.apk` را روی گوشی نصب کن. شاید لازم باشد اجازه نصب از این منبع را فعال کنی.

## نکته
این نسخه از Gradle نصب‌شده روی runner ابری استفاده می‌کند و wrapper را لازم ندارد. اگر build خطا داد، متن کامل خطا را بفرست.
برای انتشار رسمی، باید امضای release، آیکون نهایی، سیاست حریم خصوصی و تنظیمات فروشگاه اضافه شوند.
